# Sales Data Analysis

## Objective
Analyze Superstore sales data to identify:
- Monthly revenue trends
- Top-selling products
- Profit analysis

## Dataset
Superstore Sales Dataset

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data cleaning
- Revenue trend analysis
- Product sales analysis
- Profit analysis
- Data visualization

## Insights
- Technology category generated high sales
- Revenue changed monthly
- Some categories had lower profit margins
